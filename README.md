## Weather App
A simple and responsive Weather Application built using HTML, CSS and JavaScript. This project provides real - time weather information using a weather API.
## Live Demo
https://krishna-web-dev20.github.io/weather-app/
## Features 
-> Search weather by city name
-> Displays temperature details
->  Shows humidity information 
-> Weather condition updates
-> Error handling for invalid cities
-> Fully Responsive Design
-> Fast and smooth performance
-> Modern UI Design
-> Real-time Weather Data
## Technologies Used 
-> HTML
-> CSS
-> JavaScript
-> Weather API
## Project Structure
-> index.html
-> styles.css
-> script.js
## How It Works
-> Enter a city name
-> Click the Search button
-> View weather deatils instantly
-> Check temperature and humidity
-> Get real-time weather updates
